# **Café Dulce Aroma**

A cozy and interactive coffee and pastry website built with **React**, **Tailwind CSS**, and **Leaflet**. Explore cafe recipes, the brew bar, personal favorite cafe recommendations, and submit your own questions, cafe recs, or if you've tried out any of the recipes using the contact form.

## **Features**

* **Responsive Navbar** – Mobile-friendly menu with smooth transitions
* **Header Section** – Hero banner with call-to-action buttons
* **Brew Bar** – Showcase of behind-the-scenes coffee making
* **Recipes Carousel** – Interactive pastry recipe cards with download option
* **Cafe Recommendations** – Interactive map of favorite cafés with markers and popup info
* **Contact Form** – Submit messages via Web3Forms API
* **Footer** – Contact info, GitHub, LinkedIn, and portfolio links
* **Animations** – Smooth fade-in animations for a modern feel
* **Responsive Design** – Fully responsive using Tailwind CSS

---

## **Technologies**

* **React** – Front-end library for building UI components
* **Tailwind CSS** – Utility-first CSS framework for styling
* **React Leaflet** – Interactive maps
* **Web3Forms** – Form submission API
* **JavaScript / JSX** – Front-end logic and interactivity

## **Installation**

1. Clone the repository:

```bash
git clone https://github.com/Denisse030/Dulce-Aroma.git
cd Dulce-Aroma
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
